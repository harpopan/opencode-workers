## Problemas Detectados y Soluciones

### 1. Servidor de logs no respondia (ERR_INVALID_HTTP_RESPONSE)
- **Causa**: `list_directory()` retornaba bytes sin cabeceras HTTP
- **Solucion**: Anadir `send_response()`, `send_header()`, `end_headers()`, retornar `io.BytesIO`

### 2. Modelo no cargaba con contexto alto (50573)
- **Causa**: VRAM insuficiente para 4 slots x 50688 ctx
- **Solucion**: Bajar contexto a 16000

### 3. Generacion corrupta en Qwen3.5-9B
- **Causa**: Posible bug de LM Studio con modelos VL, o presion de VRAM
- **Solucion temporal**: Usar otro modelo (qwen2.5-coder, deepseek-coder)

### 4. Prompt de OpenCode no cabe en contexto pequeno
- **Causa**: System prompt de OpenCode ocupa ~8700-9200 tokens
- **Requisito**: Contexto minimo > 9500 tokens
- **Solucion**: Usar `arrancar.sh` con contexto >= 16000

### 5. Timeout del cliente
- **Causa**: Prompt processing tardaba > 2 min en Qwen3.5-9B
- **Nota**: Con qwen2.5-coder baja a ~18s, ya no es problema
