# OpenCode + LM Studio

Configuración de OpenCode con modelo local vía LM Studio.

## Requisitos

- LM Studio con servidor de API activo
- Modelo cargado en LM Studio
- OpenCode instalado

## Uso

```bash
./arrancar.sh
```

Selecciona el modelo, configura el contexto y arranca OpenCode.

## Configuracion

Ver `opencode.json` (unica fuente de verdad).
